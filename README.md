# ☕ Maria — сайт кофейни

Мобильный сайт кофейни «Maria» в стиле мобильного приложения. Это демо-проект для портфолио на чистых **HTML, CSS и JavaScript**, без фреймворков и сборки.

**Демо:** https://USERNAME.github.io/maria-coffee/

## Возможности

- **Главная**: приветствие по времени суток, статус «открыто/закрыто» по реальным часам работы, популярные позиции.
- **Меню**: 16 позиций в трёх категориях (кофе, десерты, завтраки), фильтр-чипсы, карточка товара в нижней шторке (закрывается свайпом вниз).
- **Корзина**: изменение количества, удаление с анимацией, итог. Корзина сохраняется в `localStorage`.
- **Оформление заказа**: самовывоз или доставка (бесплатно от 1000 ₽), маска телефона, демо-оплата картой (проверка номера по алгоритму Луна, живое превью карты) или наличными.
- **Экран «Заказ оформлен»**: номер заказа и анимированная галочка.
- **Отзывы**: средний рейтинг, распределение оценок, форма со звёздами 1–5. Отзывы хранятся в `localStorage`, свои отзывы можно удалить.
- **Контакты**: карта OpenStreetMap, телефон, почта, часы работы с подсветкой сегодняшнего дня.

> 💳 Оплата **демонстрационная**: данные никуда не отправляются. Тестовая карта: `4242 4242 4242 4242`, любая будущая дата и любой CVC.

## Детали

- Mobile-first вёрстка. На компьютере сайт показывается по центру, как экран телефона.
- Нижняя навигация как в приложении, с бейджем количества товаров в корзине.
- Анимации: появление карточек по очереди, «полёт» товара в корзину, тосты, шторка, валидация с «тряской» поля.
- Поддержка `safe-area` для iPhone и `prefers-reduced-motion`.
- Защита от XSS: пользовательский текст экранируется.
- SPA на hash-роутинге (`#menu`, `#cart`…), поэтому работает на GitHub Pages без настройки.

## Структура

```
maria-coffee/
├── index.html      # каркас: шапка, контейнер страниц, таб-бар, шторка
├── css/style.css   # стили и анимации (токены цветов в :root)
└── js/
    ├── data.js     # меню и стартовые отзывы
    └── app.js      # роутер, корзина, оформление заказа, отзывы
```

## Запуск локально

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Публикация на GitHub Pages

1. Создайте репозиторий `maria-coffee` на GitHub и загрузите в него код.
2. Откройте **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://USERNAME.github.io/maria-coffee/`.
